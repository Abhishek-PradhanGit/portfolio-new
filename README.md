# Abhishek Pradhan — Portfolio

A fully responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Internet is only needed for Google Fonts and Font Awesome CDN. The page itself is static.

## Before publishing
Replace these placeholders in `index.html`:
- `your.email@example.com` with your real email.
- Update the project links/text if needed.
- Add your own photo later if you want one.

## Contact form
The contact form currently opens the visitor's default email app using `mailto:`. It does not store messages in a database.

For real online message storage, connect the form to a backend such as Django REST API, Formspree, or another form service.

## Main files
- `index.html` — portfolio structure/content
- `style.css` — complete responsive design + animations
- `script.js` — navigation, scroll animations, counters, tilt effect, contact handling


## Customization added
- Warm cream/light theme by default.
- Soft-dark theme toggle (dark gray/cream, not pure black).
- Profile photo URL field: paste an image URL and click Apply.
- Resume download button expects `assets/Abhishek_Pradhan_Resume.pdf`.
- Blog Site, E-Commerce and Chat App Coming Soon sections included.
- Django backend integration is intentionally prepared as the next step.
